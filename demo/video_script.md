## 现场 3 分钟讲解结构

1. **问题（30 秒）**：说明两条 baseline——文档内手工拉线、整图生成后二次编辑——各自的重复劳动与质量风险。
2. **为什么适合 AI（30 秒）**：需求理解、信息分组和视觉隐喻需要语义判断；但精确文字、公式、箭头和版式不应交给概率式生图模型。
3. **Demo（70 秒）**：展示输入、FigurePlan、布局候选、无文字 Icon、透明抠图、确定性排版、自动 QA 与多格式导出。
4. **工程边界（25 秒）**：主视频来自真实在线运行；公开部署默认仍建议离线模式并禁用实时生图，避免泄密、费用滥用与磁盘堆积。仓库另保留固定预设，方便断网时稳定复演。
5. **量化方案（25 秒）**：用同一任务和同一验收表比较三种方法，记录首个合格版本耗时、人工操作时间、局部修改耗时、文字/关系错误和可编辑交付率。

## 答辩现场切换建议

- 网络和 API Key 都正常：先现场跑 `online`，再用仓库里的真实在线视频兜底展示完整交付链。
- 无法访问外网：播放仓库在线录屏；如需现场交互，再切换离线预设，并明确说“语义规划是固定预设，素材处理、排版、QA 和导出仍真实执行”。
- 评委追问提效数字：只报告已经录入 `benchmark/results_template.csv` 并通过统计脚本校验的实测数据；没有实测时只展示本次流水线机器耗时。
